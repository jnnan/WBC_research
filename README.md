# 人形机器人全身操作模型研究

下载 [HTML 报告](report.html) 或 [完整打包文件](report_bundle.zip)，双击 `report.html` 即可阅读。正文、样式、交互及图片均已嵌入，可离线使用；外部来源链接需要联网。

- 覆盖 UnifoLM-WLA-1.0、Delta-0、DiT4DiT、HomeBody、Lambda-0、Omega-0、GR00T N1.7、Helix 2.5。
- 核查截止：2026-10-09。
- 点击图片可放大；按模型名称筛选；“展开明细”显示补充表；打印自动展开所有明细。
- `references.json`：来源与版本索引。
- `comparison.json`：八项方法对照摘要。
- `metrics.csv`：关键试验计数与复算结果，区分成功率与进度。
- `report_bundle.zip` 仅含交付文件，不含大型原始论文/网页抓取缓存。

图片归原作者所有，已在图注中注明来源。数字为源文报告或文中注明的计算，本报告未独立复现机器人实验。
